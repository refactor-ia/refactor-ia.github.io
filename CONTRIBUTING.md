# Contribuir al sitio

## Preparación

1. Creá o elegí un issue que describa el cambio.
2. Hacé un fork y creá una rama desde tu copia.
3. Ejecutá `npm ci`.
4. Trabajá con `npm run dev`.

## Antes del pull request

Ejecutá estos controles:

```bash
npm run format
npm run check
npm test
```

Abrí un pull request desde tu fork o rama y vinculalo con el issue. Mantené los cambios acotados al sitio y describí cómo verificaste el resultado.
